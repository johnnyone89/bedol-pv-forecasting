# Data folder

Place the six released site files in this directory without renaming them:

- `01_부산신항_Busan_New_Port_FILLED.csv`
- `02_부산수처리장_Busan_Water_Treatment_FILLED.csv`
- `03_당진매립지태양광_Dangjin_Landfill_Solar_FILLED.csv`
- `04_동해태양광_Donghae_Solar_FILLED.csv`
- `05_광양항2_Gwangyang_Port_2_FILLED.csv`
- `06_하동정수장_Hadong_Water_Treatment_FILLED.csv`

The notebook checks the filenames against `configs/site_manifest.csv`.

## Target and quality columns

- Target used for the filled-target reproduction: `solar_power_filled`
- Model-imputed target rows: `target_imputed=1`
- Recommended filled-target training rows: `recommended_for_training_filled=1`
- Recommended primary evaluation rows: `recommended_for_evaluation=1`
- Data-quality annotation: `quality_flag`

The repository does **not** need cached test predictions or precomputed paper tables to re-run the method. Those should be regenerated by the notebook.
